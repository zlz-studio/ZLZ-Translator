## ขั้นที่ 1: ล็อกอิน Claude Code (ทำครั้งเดียว, 2 นาที)

> **สถานะ: ทำเสร็จแล้วเมื่อ 24 ก.ย. 2026** ข้ามไปขั้นที่ 2 ได้เลย ขั้นตอนนี้เก็บไว้เผื่อวันหนึ่งโปรแกรมแจ้งว่า "ยังไม่ได้ล็อกอิน"

เครื่องมือแปลจะเรียกใช้ Claude Code เบื้องหลัง ซึ่งต้องล็อกอินด้วยบัญชี Claude ของคุณ (บัญชีเดียวกับแอป Claude แต่ต้องล็อกอินแยกต่างหาก)

ไบนารี Claude Code บนเครื่องนี้อยู่ที่ (แอป Claude ติดตั้งแบบ Store package จึงไม่ได้อยู่ใน AppData\Roaming ตามปกติ)

```
C:\Users\Boss\AppData\Local\Packages\Claude_pzs8sxrjxfjjc\LocalCache\Roaming\Claude\claude-code\2.1.280\claude.exe
```

1. กดปุ่ม **Win + R** พิมพ์ `powershell` แล้วกด Enter
2. วางคำสั่งนี้แล้วกด Enter (คลิกขวาในหน้าต่างเพื่อวาง)

   ```powershell
   & "$env:LOCALAPPDATA\Packages\Claude_pzs8sxrjxfjjc\LocalCache\Roaming\Claude\claude-code\2.1.280\claude.exe" auth login --claudeai
   ```

   ถ้าขึ้นว่าไม่พบไฟล์ แปลว่าเลขเวอร์ชันเปลี่ยน ดูเวอร์ชันที่มีด้วยคำสั่งนี้ แล้วแก้เลขในคำสั่งข้างบนและใน `config.toml` บรรทัด `command`

   ```powershell
   Get-ChildItem "$env:LOCALAPPDATA\Packages\Claude_*\LocalCache\Roaming\Claude\claude-code"
   ```

   ถ้าเบราว์เซอร์ไม่เปิดเอง ในหน้าต่าง PowerShell จะมีลิงก์ให้ก๊อปไปเปิดเอง และมีช่องให้วางโค้ดที่ได้จากหน้าเว็บกลับมา

5. **ทดสอบว่าเครื่องมือแปลใช้ได้จริง** วางคำสั่งนี้ใน PowerShell หน้าต่างเดิม

   ```powershell
   cd "$env:USERPROFILE\Documents\Discord-Translator"; .venv\Scripts\python.exe -m core.cli read "Could you send me the updated shader files by Friday?"
   ```

   ผลที่ถูกต้อง: ได้ประโยคภาษาไทยกลับมา และบรรทัดท้ายบอก `[claude_code / haiku / x.xs]`
   ถ้าขึ้น "ยังไม่ได้ล็อกอิน" ให้ทำข้อ 2 ถึง 4 อีกครั้ง

## ขั้นที่ 2: ใช้งานปุ่มลัด (Hotkey)

1. เปิดโฟลเดอร์ `Documents\Discord-Translator` ดับเบิลคลิก **`dev\run.bat`**
2. จะมีข้อความสีน้ำเงินแว้บขึ้นว่า "Discord Translator พร้อมใช้" และมี **ไอคอนสี่เหลี่ยมสีน้ำเงิน** ที่มุมขวาล่างของจอ (system tray)
   ถ้าไม่เห็น ให้คลิกลูกศร **^** ตรง tray ไอคอนอาจซ่อนอยู่ในนั้น ลากออกมาวางไว้ข้างนอกได้
3. **ลองแปลข้อความที่ลูกค้าส่งมา**
   - เปิด Discord ลากเมาส์คลุมข้อความภาษาอังกฤษให้เป็นแถบสี
   - กด **F8** แล้วปล่อยมือ
   - รอ 2 ถึง 5 วินาที จะมีหน้าต่างดำขึ้นข้างเมาส์ บรรทัดบนสีเทาคือต้นฉบับ บรรทัดล่างคือคำแปลไทย
   - ปิดด้วยปุ่ม ✕ หรือกด Esc
4. **ลองตอบลูกค้า**
   - คลิกในช่องพิมพ์ข้อความของ Discord
   - พิมพ์ภาษาไทย เช่น `ได้ครับ น่าจะส่งให้ได้พรุ่งนี้เช้า`
   - กด **F9** แล้วปล่อยมือ **อย่าคลิกหรือพิมพ์อะไรระหว่างรอ**
   - รอ 3 ถึง 8 วินาที ข้อความไทยในช่องจะถูกแทนที่ด้วยอังกฤษ และมีหน้าต่างเล็กขึ้นให้ดู ในหน้าต่างมีบรรทัด "ลูกค้าจะอ่านว่า" ซึ่งแปลอังกฤษนั้นกลับเป็นไทยให้เช็กว่าตรงกับที่ตั้งใจไหม (ขึ้นตามมาอีก 5 ถึง 10 วินาที)
   - อ่านอังกฤษที่ได้ก่อน ถ้าพอใจกด **Enter** ส่งเอง ถ้าไม่พอใจ กดปุ่มน้ำเสียงอื่นในหน้าต่าง (ทางการ / เป็นกันเอง / สั้น) แล้วกด "ก๊อป" ไปวางแทน
   - ถ้าอยากแปลแค่บางส่วน (เช่นช่องพิมพ์มีรูปหรืออีโมจิอยู่ด้วย) ลากคลุมเฉพาะข้อความไทยนั้นแล้วกด **F9** ส่วนอื่นจะไม่ถูกแตะ
   - ข้อความในหน้าต่างผลแปลลากคลุมแล้วกด Ctrl+C ได้ทุกช่อง หรือคลิกขวาเพื่อก๊อป
   - ปุ่ม **แปลกลับเช็ก** จะแปลอังกฤษที่ได้กลับเป็นไทยให้ดูว่าความหมายตรงไหม
5. **ถ้าอ่านแล้วยังงง** ลากคลุมข้อความลูกค้าแล้วกด **Shift + F8** จะได้คำอธิบายว่าลูกค้าพูดเรื่องอะไร ต้องการให้ทำอะไร และอารมณ์เป็นยังไง
6. **ถ้าพิมพ์อังกฤษเองแต่ไม่มั่นใจ** พิมพ์ในช่องแชทแล้วกด **Shift + F9** จะแก้ไวยากรณ์ให้
7. เมนูที่ไอคอน tray (คลิกขวา): เปลี่ยนน้ำเสียงเริ่มต้น, เปิดไฟล์ตั้งค่า, ดูจำนวนครั้งที่ใช้วันนี้, ออกจากโปรแกรม
8. **ให้เปิดเองตอนเปิดเครื่อง**: คลิกขวาไอคอน tray ติ๊ก **เปิดอัตโนมัติเมื่อเข้า Windows** (บนเครื่องนี้เปิดไว้แล้ว) ติ๊กออกเพื่อยกเลิก
9. **เปิด/ปิดชั่วคราว**: คลิกซ้ายที่ไอคอน tray หนึ่งครั้ง ไอคอนสีเทา = ปิดอยู่ (F8/F9 ไม่ทำงาน) คลิกอีกครั้งเพื่อเปิด

2. กด **Create API key** เลือกโปรเจกต์ใดก็ได้ (หรือสร้างใหม่) จะได้คีย์ยาวๆ ขึ้นต้นด้วย `AIza...` กด Copy

## ขั้นที่ 4: ตั้งค่า Discord App (ทางเลือก, 5 ถึง 10 นาที)

ทำให้คลิกขวาที่ข้อความใน Discord แล้วแปลได้เลย และใช้จากมือถือได้ (ตอน PC เปิดโปรแกรมอยู่)

### 4.1 สร้างแอปใน Discord Developer Portal

1. เปิด https://discord.com/developers/applications ล็อกอินด้วยบัญชี Discord ของคุณ
2. กดปุ่ม **New Application** มุมขวาบน
3. ตั้งชื่อ เช่น `Translator` ติ๊กยอมรับข้อตกลง แล้วกด **Create**
4. (ทางเลือก) ในหน้า General Information ใส่รูปไอคอนได้

### 4.2 เปิดให้ติดตั้งแบบ User Install

1. เมนูด้านซ้าย คลิก **Installation**
2. หัวข้อ **Installation Contexts** ติ๊ก **User Install** (ติ๊ก Guild Install ไว้ด้วยก็ได้ ไม่เสียหาย)
3. หัวข้อ **Install Link** เลือก **Discord Provided Link**
4. หัวข้อ **Default Install Settings** ส่วน User Install ให้ Scopes มี `applications.commands` (ค่าเริ่มต้นมีอยู่แล้ว)
5. กด **Save Changes** แถบเขียวด้านล่าง
6. ก๊อป **Install Link** เก็บไว้ (จะใช้ในข้อ 4.4)

### 4.3 เอา Token มาใส่ในโปรแกรม

1. เมนูด้านซ้าย คลิก **Bot**
2. กด **Reset Token** แล้วกด **Yes, do it!** ถ้าบัญชีเปิด 2FA จะให้ใส่รหัสจากแอปยืนยันตัวตน
3. กด **Copy** ใต้ token (ตัวอักษรยาวๆ มีจุดคั่น 2 จุด) **token นี้เห็นได้ครั้งเดียว** ถ้าปิดหน้าไปต้อง Reset ใหม่
4. คลิกขวาไอคอน tray เลือก **ตั้งค่าคีย์และบัญชี...** วาง token ในช่อง `DISCORD_TOKEN`
5. กด **บันทึก** โปรแกรมจะเปิด Discord app ให้เองใน 10 วินาที
6. ในหน้า Bot เดียวกัน ไม่ต้องเปิด Privileged Intents ใดๆ (Message Content Intent ไม่จำเป็น เพราะคำสั่งคลิกขวาได้เนื้อหาข้อความมาอยู่แล้ว)

### 4.4 ติดตั้งแอปเข้าบัญชี Discord ของคุณ

1. เปิดลิงก์ Install Link จากข้อ 4.2 ในเบราว์เซอร์
2. จะมีให้เลือก 2 แบบ เลือก **Add to My Apps** (ไม่ใช่ Add to Server)
3. กด **Authorize**
4. ในแอป Discord ไปที่ Settings > Authorized Apps จะเห็นชื่อแอปอยู่ แปลว่าสำเร็จ

### 4.5 เปิดโปรแกรมและทดสอบ

1. ถ้าโปรแกรม Hotkey เปิดอยู่แล้ว: คลิกขวาไอคอน tray จะเห็น "Discord app: กำลังทำงาน" (เปิดให้เองเมื่อพบ token) ถ้ายังไม่เปิดให้ดับเบิลคลิก `dev\run.bat` ไม่มีหน้าต่างค้าง ตรวจสอบได้จาก `data\discord.log` ซึ่งจะมี 2 บรรทัดนี้

   ```
   ... synced 5 commands: en, th, fix, แปลเป็นไทย, อธิบายข้อความนี้
   ... logged in as Translator#1234
   ```

   (เปิด/ปิด Discord app ได้จากเมนูไอคอน tray ปิดโปรแกรม Hotkey เมื่อไหร่ Discord app ก็ปิดตาม)
2. ใน Discord ไปที่แชทไหนก็ได้ (DM ตัวเองก็ได้) พิมพ์ `/en` จะเห็นคำสั่งขึ้นมา ใส่ข้อความไทยแล้ว Enter
   ผลจะขึ้นเป็น 2 ข้อความที่ "Only you can see this": ข้อความแรกคืออังกฤษล้วนๆ (ก๊อปไปวางในช่องพิมพ์แล้วกด Enter เอง จะขึ้นเป็นชื่อคุณ) ข้อความที่สองคือแปลกลับเป็นไทยให้เช็ก พร้อมปุ่มแปลใหม่แบบน้ำเสียงอื่น
3. ลองคลิกขวาที่ข้อความใดๆ เลื่อนไปที่ **Apps** จะเห็น **แปลเป็นไทย** และ **อธิบายข้อความนี้**
4. ถ้าคำสั่งยังไม่ขึ้น กด **Ctrl + R** ใน Discord เพื่อรีโหลด หรือรอ 1 ถึง 2 นาที
5. บนมือถือ: กดค้างที่ข้อความ เลือก **Apps** ที่ท้ายเมนู

### 4.6 ข้อจำกัดที่ควรรู้

- แอปไม่โพสต์อะไรลงแชทเอง ข้อความที่ส่งจริงต้องมาจากช่องพิมพ์ของคุณ จึงขึ้นเป็นชื่อคุณเสมอ
- ข้อความยาวเกิน 1900 ตัวอักษรจะถูกตัด
- ทำงานเฉพาะตอน PC เปิดโปรแกรม Hotkey อยู่ (ไอคอน tray)

## ขั้นที่ 6: ปรับให้แปลตรงใจ

- **`glossary.md`** เปิดด้วย Notepad เติมชื่อโปรเจกต์ ชื่อลูกค้า ศัพท์ที่ห้ามแปล และแนวทางน้ำเสียง เขียนเป็นไทยได้เลย บันทึกแล้วเลือก "โหลดการตั้งค่าใหม่" ที่ tray
- **`config.toml`**
  - `default_tone` น้ำเสียงเริ่มต้น `friendly` / `formal` / `brief`
  - `[modes]` ถ้าอยากให้ตอบเนียนขึ้นเปลี่ยน `reply = "opus"` (กินโควต้ามากขึ้น) ถ้าอยากไวขึ้นเปลี่ยนเป็น `"haiku"`
  - `[hotkeys]` ถ้าปุ่มชนกับโปรแกรมอื่น เช่นเปลี่ยนเป็น `"ctrl+f8"` และมีเมนู "หยุดปุ่มลัดชั่วคราว" ที่ tray สำหรับตอนเขียนโค้ดใน Unity/Visual Studio ที่ใช้ F8/F9
  - `provider_order` เช่น `["gemini", "claude_code"]` ถ้าอยากใช้ Gemini เป็นหลัก
